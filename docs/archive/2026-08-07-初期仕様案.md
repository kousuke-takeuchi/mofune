# サーバーレス型 幼稚園連絡PWA 仕様書

## 1. システム概要

### 目的

- 園児・保護者・先生間の連絡を行う
- 自前サーバーでユーザーデータを保持しない
- 外部ストレージをデータ同期基盤として利用する
- 複数管理者端末が通知送信を担当する
- PWAとして提供する

### 基本思想

本システムはローカルファースト設計とする。

- 各端末がローカルDBを保持する
- 外部ストレージは共有データ領域として利用する
- 通知処理は権限を持つ端末が担当する
- 運営側の常時稼働サーバーを不要とする

```
Cloud Server
    ↓
 なし

Storage
(Google Drive等)
    ↓
共有データ

Client
(PWA)
    ↓
ローカルDB
```

# 5. イベント駆動同期

すべての変更をイベントとして保存する。

## 例：写真追加イベント

```json
{
  "id": "evt_00001",
  "type": "FILE_CREATED",
  "author": "teacher001",
  "target": "class_a",
  "file": "abc123.jpg",
  "time": "2026-08-07T10:00:00"
}
```

## 同期処理

```
アプリ起動

↓

events確認

↓

未処理イベント取得

↓

IndexedDB更新

↓

通知処理
```

# 10. 鍵管理方針

## 基本方針

- 一般保護者には秘密鍵を渡さない
- Ownerのみ通知送信権限を持つ
- Owner追加・削除はOwnerが管理する

## 将来対応

- 鍵ローテーション
- Ownerごとの子鍵
- 有効期限付き権限

# 11. 競合処理

複数ユーザーが同時投稿する可能性を考慮する。

## イベントID

```
timestamp + random
```

例:

```
20260807101530-a82f
```

イベントソーシング方式により競合を回避する。
