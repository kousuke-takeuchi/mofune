プライバシーポリシー

最終更新: 2026年8月8日

要点。 Mofune はサーバーもデータベースも持ちません。お知らせ・写真・連絡先などのデータは、グループが用意した保管場所に暗号化された状態で置かれます。私たちはそれを受け取らず、読むこともできません。

1. 事業者

Mofune は個人が開発・公開しているオープンソースのソフトウェアです。ソースコードは GitHub リポジトリで公開しています。

2. 私たちが取得しない情報

Mofune の運営者は、次のいずれも取得しません。

  • お知らせの本文、添付した写真やPDF、フォームの回答
  • 欠席・不在の連絡の内容
  • メンバーの氏名・表示名・メールアドレス・連絡先(ログインにも使います)
  • パスワード・暗号鍵
  • 誰がいつ何を読んだかの記録

これらは仕組み上、私たちに届きません。データはグループが用意した保管場所へ、送信前に利用者の端末で暗号化されてから置かれます。復号に必要な鍵はグループの中だけにあります。

3. 端末に保存される情報

アプリは表示を速くするため、取得済みのお知らせや添付、未読の印を利用者の端末内 (ブラウザの IndexedDB) に保存します。これは端末の中だけの控えで、外部へ送信されません。パスワード・暗号鍵・保管場所の資格情報は端末に保存しません。

4. 保管場所の事業者について

データの置き場は各グループが選んで契約します。ファイルの大きさ・更新時刻・パスの形はその事業者から見えますが、中身は暗号化されているため読めません。保管場所の事業者による取り扱いは、そのサービスのプライバシーポリシーが適用されます。

5. このサイトについて

  • アクセス解析を設置していません。
  • 広告を掲載していません。
  • クッキーを利用していません。
  • フォントを含むすべてのファイルをこのサイトから配信しています。外部の CDN へ接続しないため、閲覧しただけで第三者に IP アドレスが渡ることはありません。
  • サイトは GitHub Pages で配信しているため、配信元である GitHub 社のアクセスログには通信の記録が残ります。

6. 通知について

メールでの通知は、担当者の端末からメールアプリを開いて送る方式です。私たちのサーバーを経由しません。グループが任意で通知用の関数サービスを設置した場合も、中継されるのは「新しい連絡がある」という合図だけで、本文や個人情報は載せません。

7. 第三者への提供

そもそも取得していないため、提供・販売・共有のいずれも行いません。

8. お問い合わせ

ご質問は GitHub の Issues からお願いします。

9. 変更

内容を変更したときは、このページの最終更新日を改めます。重要な変更はリポジトリの変更履歴からも追えます。
