# Mofune

[English version / 英語版はこちら](README.md)

**サーバーレス・E2E暗号化のグループ連絡PWAアプリ。**

Mofuneは、お知らせ・写真・不在連絡・埋め込みフォームでグループの担当者と参加者をつなぎます。運営者はサーバーを1台も持ちません。各グループのデータは、そのグループが自分で持つクラウドストレージに完全暗号化されて保存され、アプリ本体はただの静的ファイルです。

想定する利用者は、名簿を持って定期的に一斉連絡を行う小規模グループ全般です(園・学童・マンション管理組合・サークル・地域団体・部活動など)。

> 現在のステータス: **設計フェーズ**。要件書・設計書・デザインは完成済み、実装は未着手です。

## なぜ作るのか

この種の連絡アプリは通常ホスティング型サービスであり、月額費用がかかり、写真や家庭の情報を事業者が預かり、その事業者が存続しなければアプリも止まります。Mofuneは逆の構成を取ります。

- **中央サーバー・データベース・常駐プロセスなし。** アプリは静的PWA(GitHub Pages等)。データはグループ自身が管理するストレージに置かれる
- **参加者のアカウント登録ゼロ。** 紙で配られたIDとパスワードだけでログイン。Googleアカウントもストレージのアカウントも不要
- **E2E暗号化+公開ストレージ。** すべてクライアント側で暗号化。ストレージは誰でも読める状態でもデータは秘匿される。アクセス制御はサーバーのACLではなく「鍵の所持」
- **運営者なしでスケールする。** グループごとに独立したテナント(独自のストレージと鍵体系)。グループが1,000に増えても運営者のコストはゼロのまま

## 機能

- グループ全体またはサブグループ単位でのお知らせ・写真・PDF共有。1つの投稿を複数のサブグループへ同時配信できる
- サブグループは入れ子にできる。子サブグループ宛の配信は、その中だけに届く
- 添付ファイルはメンバーのみ閲覧可。ストレージのURLを知っていても部外者には暗号文しか見えない
- メッセージへのフォーム埋め込み。**回答を復号できるのはフォーム作成者だけ**(グループの管理者でも読めない)
- 参加者からの不在連絡(欠席 / 遅れます / 早く帰ります)
- アプリを閉じていても届く多段構成の通知
- オフラインファースト: 圏外でも閲覧でき、投稿は復帰後に自動送信
- 1人で複数グループを運営可能。グループごとにストレージを選べる

既読の共有は行いません。未読バッジは端末ローカルの計算のみで、閲覧行動はどこにも送信されません。

## アーキテクチャ概要

```
[必須]  静的PWA          1デプロイで全グループ共用(GitHub Pages等)
[必須]  ストレージ        グループごとに選択: S3互換 / Drive / Dropbox / WebDAV
[必須]  inbox            参加者からの上り経路。ストレージネイティブ機構(presigned PUT)
[任意]  サーバーレス関数   Web Push配送のみ。GASまたはCloudflare Workers、いつでも撤去可能
[保険]  メール(mailto:)   担当者のメーラーから手動一括送信。外部API依存ゼロ
```

設計を決定づけた技術的事実が2つあります(プロトコル仕様・公式ドキュメントで確認済み)。

1. **ブラウザからWeb Pushは送信できない。** PushサービスのエンドポイントはCORSを許可していないため、純粋な静的アプリは通知を配送できません。そのためpush送信は*任意*の関数層に切り出し、各グループが無料で自己展開できる形にしました。関数がなくても全機能は動作します
2. **サーバーなしの認証=復号。** ログインはパスワードから鍵を導出し(Argon2id+紙でのみ配布するペッパー)、公開ストレージ上のキーストアを復号してスコープ鍵を取り出す処理そのものです。パスワードが違えば単に復号に失敗します

通知は受信者ごとに多段フォールバックします: Web Push(関数層導入グループ) → 宛先をBCCに自動設定した `mailto:` リンクで担当者のメールアプリを開く手動一括送信 → 最終保証としてアプリ起動時の同期。すべての通知は無内容(「新着があります」のみ)で、第三者経路に個人情報は一切乗りません。

## 技術スタック(予定)

Vue 3 · TypeScript · Vite · PWA / Service Worker · Dexie.js (IndexedDB) · Web Crypto API · Argon2id (hash-wasm)

外部CDNへは実行時に接続しません。フォント・WASMを含むすべてのアセットを同梱します。
